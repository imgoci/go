# imgoci/go

imgoci/go is the canonical Go implementation of the imgoci release format ([spec v1 draft, 2026-08-16](https://github.com/imgoci/spec), commit `46d18b74cc407ac7d61ded7692fc42b644f4d1e2`). The library is under active development. Related projects include [bigoci](https://github.com/imgoci/bigoci) and [go-oci-blob](https://github.com/imgoci/go-oci-blob).
