# imgoci/go

imgoci/go is the canonical Go implementation of the imgoci release format ([spec release v0.1.0](https://github.com/imgoci/spec), commit `8083159daebe15dc1d78da3e8a03b6b80526d427`). The library is under active development. Related projects include [bigoci](https://github.com/imgoci/bigoci) and [go-oci-blob](https://github.com/imgoci/go-oci-blob).
